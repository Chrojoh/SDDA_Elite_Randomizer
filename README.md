# SDDA Elite

## Publish

Extract the ZIP and upload its contents to the root of your GitHub repository. Keep the icons folder in place. In Settings → Pages, select Deploy from a branch, then main and / (root). Share the HTTPS address shown in Pages.

## Install

Open the published link once while connected. In Chrome on Android, open the menu and choose Install app or Add to Home screen, then choose Install if prompted. In Safari on iPhone, use Share → Add to Home Screen and turn on Open as Web App if shown.

Launch SDDA Elite from the home-screen icon. To check that the first visit finished saving the app, close it, turn on airplane mode, turn off Wi-Fi, and reopen it from the icon. Randomize works offline with the files saved on the device. If the browser's site data is cleared, open the online link again to restore offline access.

The app has no external fonts, libraries, accounts, or data feeds. SDDA-Elite.html also opens directly as a standalone file in a browser.
